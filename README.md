# 🍽️ Yummy – Recipe Finder

**Yummy – Recipe Finder** is a simple and attractive recipe website built using HTML, CSS, and JavaScript. It helps users explore different recipes, search for their favorite dishes, view ingredients and cooking instructions, and save recipes to their favorites.

## ✨ Features

* 🥗 **Browse Recipes:** Explore a variety of delicious recipes.
* 🔍 **Search Recipes:** Find recipes by name, description, or category.
* 🍳 **Category Filters:** Filter recipes by Breakfast, Lunch, Dinner, and Dessert.
* ❤️ **Favorites:** Add or remove recipes from your favorites.
* 📖 **Recipe Details:** View ingredients, preparation time, and step-by-step cooking instructions.
* 🎨 **Attractive UI:** Colorful design with recipe images and interactive buttons.

## 🛠️ Technologies Used

* **HTML** – Structures the website.
* **CSS** – Styles the website and creates a responsive layout.
* **JavaScript** – Handles search, filtering, favorites, and recipe details.
* **Unsplash Images** – Provides recipe images.
